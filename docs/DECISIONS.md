# Product decisions

- 2026-10-29 — **ChatGPT is the only additional provider integration in the current activation scope.**
  Why: finish the existing connector and onboarding paths before activation; ChatGPT's remaining submission blocker is the demonstration video, per the founder's current assessment.
  Rejected: adding more provider integrations during this slice, which would expand the work before the existing first-approval experience is ready.
  Revisit when: the founder explicitly reopens provider scope after the current activation work.

- 2026-09-28 — **Prioritize connection and approvals inside existing agent tools.**
  Why: users should find Sanction and resolve exceptions where they already work; the dashboard remains an administrative fallback.
  Rejected: making dashboard visits the primary adoption path, because they interrupt the agent workflow.
  Revisit when: a verified host workflow shows which setup or administration tasks still require the dashboard.
